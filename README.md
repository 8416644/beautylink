# BeautyLink

אפליקציה שמחברת בין בעלות מקצוע בתחום היופי לבין לקוחות.

- מסמך האפיון: https://claude.ai/artifact/D3GGvQHXLYBS1zjJnnzhsP
- עיצוב המסכים: https://claude.ai/artifact/KcER44me19Sz7YfgK3MDcJ

## מבנה הפרויקט

| תיקייה | מה יש בה |
| --- | --- |
| `supabase/migrations` | מבנה מסד הנתונים והרשאות הגישה |
| `supabase/seed.sql` | קטגוריות ותת-קטגוריות התחלתיות |
| `app` (בקרוב) | האפליקציה ללקוחות ולבעלות מקצוע: React Native עם Expo, לטלפון ולאתר |
| `admin` (בקרוב) | דשבורד המנהל: Next.js |

## מה צריך להתקין לפני שמתחילים

1. **Node.js** בגרסת LTS מהאתר הרשמי: https://nodejs.org
2. **Git**: https://git-scm.com/download/win
3. אחרי ההתקנה צריך לסגור ולפתוח מחדש את Claude, כדי שהפקודות `node` ו-`git` יזוהו.

## חשבונות

| שירות | עלות | בשביל מה | מתי צריך |
| --- | --- | --- | --- |
| Supabase | חינם בהתחלה | מסד נתונים, התחברות, אחסון תמונות | עכשיו |
| Expo | חינם | בנייה והפצה של האפליקציה | עכשיו |
| Apple Developer | 99 דולר לשנה | פרסום ב-App Store | לפני ההשקה (האישור לוקח כמה ימים) |

## שלב 1: סדר הבנייה

1. הקמת הפרויקט ומסד הנתונים
2. הרשמה והתחברות (גוגל, אפל, מייל)
3. הרשמת בעלת מקצוע, פרופיל ותיק עבודות, ואישור מנהל
4. חיפוש, סינון ומפה
5. יומן, זמינות והזמנת תורים (כולל תור ידני וחסימות)
6. תזכורות פוש
7. ביקורות ומועדפים
8. דשבורד מנהל בסיסי
